## 접근 방식

### C1 기울여도 작아지지 않게
스테이지 변환을 `translateY(−sinθ·hn) perspective(P) rotateX(θ) scaleY(k)` 로 바꾼다(θ = tilt × 66°). 전부 `--tilt` 파생 CSS 변수라 드래그 중 JS 재렌더가 없다.

- 권장안 `k = 1/cos θ`, `P = 2000px` 를 그대로 쓰면 지판 평면 깊이가 k 배로 늘어 원근 축소가 커진다(보드 240px · 66° → 먼 쪽 폭 79%, 먼 줄 간격 ≈ 63%). 계약의 90% 를 못 맞춘다. 그래서 원근 세기를 직접 정한다:
  - `δ = sin θ × .06` — 먼 쪽 가장자리의 원근 축소량(먼 쪽 폭 = 1/(1+δ), tilt 1 에서 ≈ 5%).
  - `T = 1 − sin θ × hn / boardH` — 옆면이 화면에 차지하는 몫을 뺀, 보드가 써도 되는 높이 비율. 보드 + 옆면 = 평면 보드 높이 → 레이아웃 박스를 가득 채우고 위로 넘치지 않는다.
  - `k = T × (1 + δ) / cos θ`, `P = k × boardH / .06` (평면 깊이 k·boardH·sinθ 를 δ 로 나눈 값).
  - 줄 간격(화면) = T(1+δ)/(1+δt)² (t = 0 가까운 줄 … 1 먼 가장자리). tilt 1 · 6현: 가까운 줄 ≈ .98, 먼 줄 ≈ .91.
- JS 가 넣는 변수: `--fb-hn`(옆면 높이 px, 기존) + `--fb-bh`(지판 높이 px, 신규). 둘 다 단위 없는 수라 calc 나눗셈이 된다.
- 옆면 두께 계수 `hn = sg × .55 → .35`: 옆면 몫이 크면 T 가 작아져 90% 를 못 맞춘다(.55 → T = .915).
- 마크·라벨·줄 이름의 세로 보정(`--fb-sy`)과 마크 축소(`--fb-m`)는 삭제. 화면 종횡비 = T(1+δ)/(1+δt) ∈ [.95, 1.0] 이라 보정 없이 원에 가깝다. 실측해서 0.9~1.1 밖이면 `--fb-sy` 를 되살린다.
- 옆면(`rotateX(-90deg)`)은 두께가 z 방향이라 scaleY 영향을 받지 않는다 → `translateY(−sinθ·hn)` 그대로 맞는다.
- 검토한 대안: (a) `k = 1/cos θ` 고정 + P 2000 — 위 이유로 기각. (b) 보드를 위로 넘치게 두고 k 를 키움 — 위 요소(헤더)와 겹칠 수 있어 기각. (c) JS 에서 행렬 계산 — 드래그 중 재렌더 필요, 기각.

### C2 줄 간격 계수
`layout(n, lo, hi, fill?, stringGap = 1)` — 비 fill 일 때 `sg *= stringGap`. 나머지 공식은 그대로. `Fretboard` 는 fill 이면 1 을 넘긴다.

### C8 표적 강조
`.fb-mark.st-target` 테두리 `--text` 2.5px + 바깥 링(두 번째 circle `.fb-ring`, stroke `--ok`). `fb-pulse` 키프레임을 `scale 1 → 1.08` 로 바꿔 마크·링에 건다(`scale` 속성이라 다른 transform 과 안 겹침, reduced-motion 은 전역 규칙으로 정적). `.fb-ring` 은 `.fb-mark` 클래스를 달지 않는다(E2E `.fb-mark.st-target` 개수 유지).

## 변경 사항 (계획 대비)
- **원근 세기를 보드 종횡비로 제한**: `δ = sin θ × .06` 고정이면 넓은 보드(1440, 16칸)의 좌우 끝 글자가 7° 쯤 기울어(전단 = δ × 폭 / 2높이) 이탤릭처럼 보였다. `--fb-e = min(.06, 지판 높이/전체 폭 × .18)` 로 바꾸고 JS 가 `--fb-ar` 를 넣는다. 폰(좁은 창)은 .06 그대로, 1440 16칸은 ≈ .04.
- **세로 보정 `--fb-sy` 는 삭제 대신 4% 로 축소**: 보정 없이 마크 세로/가로가 .92~.99(가운데), 끝 열 .85 였다. 마크·링·라벨·줄 이름에 `scaleY(1 + tilt × .04)` → .91~1.04.
- 라벨 `font-weight: 700`(기울였을 때만)도 삭제: 글자가 평면 크기라 필요 없다.
