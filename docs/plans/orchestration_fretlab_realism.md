## 2. 가정
- A1 "레이아웃 스타일 예외" = 프렛보드 **안**(지판·프렛·인레이·줄)은 DrillDown 무채색 토큰을 벗어난 실물 색을 써도 된다. 프렛보드 밖(번호·줄 이름·마크·상태색)은 토큰 유지.
- A2 지판 색은 테마에 따르고 사용자 옵션은 두지 않는다(요청 없음).
- A3 그립(fill) 모드도 같은 그리기를 쓴다. 그립은 4~5칸 창이라 간격 완화가 눈에 덜 띄지만 같은 함수.
- A4 실물 스케일 길이·프렛 폭 수치는 25.5인치 스트랫 기준.
- A5 QA 자동 검사 "토큰 밖 색 0" 은 이후 `fretboard.css` 의 `--fb-*` 정의 줄을 제외하고 센다.

## 3. 공유 계약
변경 없음. `FretboardProps`·`layout()` 의 반환 필드명은 유지하되 `x(f)` 가 비선형이 되고 `cw` 는 **평균** 칸 폭(마크 지름 계산용으로 각 칸 폭 `cwAt(f)` 추가 가능 — fretboard 내부 전용).
