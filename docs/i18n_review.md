유지·제안:
- study `stats` `Accuracy {p}% ({n} tries)` — **유지**. n = 1 이면 "(1 tries)" 가 된다. 자연스러운 대안은 `Accuracy {p}% (tries: {n})` 또는 `Accuracy {p}% · {n}×` 이지만, `src/features/study/logic.check.ts`(D 소유)가 `'Accuracy 80% (2 tries)'` 를 그대로 단언하고 있어 바꾸면 `npm run check` 가 깨진다. → 오케스트레이터 결정 필요(§5).
- `picked` 는 오답을 많이 찍으면 "Picked 14 of 12" 가 될 수 있다(정답 수보다 많이 찍음). 과다 선택을 알려 주는 효과가 있어 그대로 둔다.
- 스케일 이름은 Title Case(`Harmonic Minor`), UI 문구는 Sentence case(`Reset to defaults`, `Position system`) — 일관됨. 튜닝도 Sentence case + 고유 표기(`Half-step down`, `7-string standard`, `Drop D`).
- `Flat`(기울기 0%) — 음악 앱이라 ♭ 로 읽힐 여지가 있으나 기울기 슬라이더 옆 출력이라 문맥이 분명. 유지.
- `Listen / Grade / Retry / Reset / Next position / Show menu / Lower frets / Rotate to landscape` 등 버튼·aria 문구는 짧은 명령형으로 이미 자연스럽다.

A6 plan 의 'L6 검토 후보' 결정:
- `ディミニッシュ (半・全)` — **유지**. en/ko 와 꼴이 같고 `(全・半)` 과 짝을 이룬다. 통칭 コンディミ 는 이름이 아니라 검색 별칭이 맞다 → `aliases` 추가 요청(§5).
- `リディアンドミナント` — **유지**. リディアン♭7 도 흔하지만 en `Lydian Dominant` 와 대응하고 이 표기도 표준.
- 그룹 `民族音階` — **유지**. `民族` 단독은 어색하고 `エスニック` 보다 뜻이 분명하며 4자로 칩에 짧다.
- 인도 라가 음차 — `マールワー`·`プールヴィー` 유지, `トーディ` 만 장음 통일(위 표).
- `ペロッグ` — **유지**(ペロッグ音階 가 통용 표기).
- 일본 전통 음계는 한자(平調子·陰旋法·陽旋法·岩戸調子·雲井調子), **가나 병기 안 함** — 일본어 사용자는 읽을 수 있고 병기하면 목록 줄이 길어진다. 가나 검색은 별칭으로 해결(§5).

유지: 카타카나 음악 용어(ペンタトニック·ハーモニックマイナー·メロディックマイナー·ディミニッシュ·ホールトーン·ビバップ·ドリアン·オーギュメント·オルタード·クロマチック·ナポリタン) 표준 표기 확인. 복합어는 가운뎃점 없이 붙여 쓰기로 통일돼 있다(`マイナーペンタトニック`), 가운뎃점은 `(全・半)`·`採点・もう一度` 같은 병렬에만. UI 버튼은 명사형(採点·もう一度·試聴·閉じる·完了·終了). `横向きにしてください`(회전 안내)·`開いてください`(PC 안내)는 버튼이 아니라 안내문이라 ください 유지. 용어집(穴埋め·追いかけ·表示·傾き·言語 등) 일치. `ラベル`(Labels) 유지 — `表記` 가 더 자연스럽지만 같은 시트의 `表示`(View)와 한 글자 차이라 헷갈린다.

## 4. 의미 일치 · 자리표시자 · 길이

- 자리표시자: 5개 `strings.ts` 의 모든 키에서 en/ko/ja 의 `{x}` 집합이 같고 빈 값이 없음(임시 스크립트로 비교 — `placeholders ok`).
- 의미 일치: 위 표의 `unmute`·`showMenu`·`prevWin`·`reset`·`flat` 5건이 언어 간 뜻이 어긋나 있어 맞췄다. 그 밖은 일치.
- 길이: `npx vite --port 8047` + Playwright(Edge) 로 ja·en·ko × 390×844(연습 보기·채우기·따라치기, 스케일 시트 탭 3개, 옵션 시트) / 844×390(그립 시작·띠 보기·따라치기), ja 1440×900 총 35장. 가로 넘침 0, 한 줄 문구(버튼·세그먼트·배지·제목·진행 표시)의 줄바꿈 0, 콘솔 오류 0. 가장 긴 조합(ja `A ディミニッシュ (半・全) · レギュラー · CAGED 1/5`)도 390 요약 버튼 한 줄에 들어간다. `レギュラー` 는 `スタンダード` 보다 1자 짧다.
- 그립 시작 타일(`スタート — 横向きの全画面で開く`)·도움말은 여러 줄이 허용되는 블록이라 대상 아님(844×390 에서 타일 한 줄, 도움말 두 줄).

## 5. 오케스트레이터에 넘기는 항목(소유 범위 밖)

1. `src/features/study/logic.check.ts` 가 en `stats` 문구를 단언 → `(1 tries)` 를 고치려면 그 파일과 함께 바꿔야 한다. 제안: `Accuracy {p}% (tries: {n})`.
2. `scales.ts` 의 `aliases`(수정 금지 필드)에 일본어 통칭·읽기 추가 제안: `diminished-hw` ← `コンディミ`, `lydian-dominant` ← `リディアン♭7`, `hirajoshi` ← `ひらぢょうし`, `in-sen` ← `いんせんぽう`, `yo` ← `ようせんぽう`, `iwato` ← `いわとぢょうし`, `kumoi` ← `くもいぢょうし`.
3. en 문구 3건이 바뀌었다(`Picked {b} of {n}`, `{w} wrong`, `Esc`) — E2E 가 `Picked 0 / N answers` 를 찾는다면 `Picked 0 of N` 으로 갱신 필요(QA6).
4. `src/features/picker/search.check.ts` 의 픽스처 `マイナー・ペンタトニック` 는 실제 데이터(`マイナーペンタトニック`)와 표기가 다르다 — 검사는 통과하지만 픽스처를 맞추면 좋다.
